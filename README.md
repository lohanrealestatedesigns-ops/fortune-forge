# Fortune Forge

Build a premium, institutional-grade financial services web application for "JAM-FORTUNE FINANCIAL SERVICES LTD"[cite: 6]. The institution is a fully established micro-finance entity incorporated by the federal government, operating since 2008[cite: 6]. 

CRITICAL DESIGN INSTRUCTION: This must NOT look like a generic SaaS template or a lightweight startup. It must feel like an established, highly secure, and deeply trusted Nigerian financial institution. Use brutalist structural grids, generous negative space, sharp edges (use `rounded-none` or `rounded-sm`), and strong visual hierarchy. Use React, Tailwind CSS, Shadcn UI, and Framer Motion for deliberate, professional reveal animations.

**Global Design System & Vibe:**

*   **Theme:** Institutional Trust, Financial Empowerment, and Nationwide Accessibility[cite: 6].

*   **Color Palette:** Use "Trust Navy Blue" and "Slate Gray" for primary backgrounds and typography to convey security. Use a rich "Corporate Bronze/Gold" as the primary accent color for Call-to-Action (CTA) buttons, thin structural dividers, and active hover states to reflect their award-winning pedigree[cite: 6]. 

*   **Typography:** Use a classic, authoritative Serif font (like Merriweather or Playfair Display) for main headings. Use a highly legible Sans-Serif (like Inter or Roboto) for all body text, financial figures, and terms.

*   **Navigation:** A thick, sticky glassmorphism header. Left: Text Logo "JAM-FORTUNE FINANCIAL SERVICES LTD" with a subtle sub-text "GOD 1ST"[cite: 6]. Center Links: Personal Loans, Business Finance, Appliance Scheme, About Us, Contact. Right: A solid Navy Blue button: "Apply for Loan".

**PAGE STRUCTURE & CONTENT:**
